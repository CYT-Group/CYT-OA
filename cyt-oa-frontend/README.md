# CYT OA

面向企业内部协同与人事管理的一体化系统。本目录为 **cyt-oa-frontend 前端**，
在同一套页面里承载员工「个人中心」与管理员「控制台」两个入口，
配合 `cyt-oa-backend` 后端使用。

## 主要功能

- **两级导航**：左侧按区块分组，一级项可展开二级项，二级项直接带查询参数落到对应视图。
- **个人中心**：概览摘要、大促与新品节奏日历、我的提醒、报告时间线与点评、
  自助办事、审批待办、我的团队、个人资料与足迹。
- **管理控制台**：组织与人事、薪酬与考勤、OA 台账、字典与权限等页面。
- **门户管理**：`/portal` 集中承接旧 Portal「后台管理 / HR 管理」，按原能力位显示菜单；包括内容、培训、物资、文档、签收、合同、庆祝和简历。
- **入口分批上线**：系统管理员在 `/portal/rollout` 逐项或整组控制迁移的 20 个业务菜单。修改保存后统一生效，管理中心与设置入口固定保留；角色权限仍独立生效。
- **配置化台账页**：绝大多数增删改查由菜单项声明驱动，共用一个通用表格与表单组件，
  字段类型、字典下拉与权限按钮一并配置。
- **登录**：线上走企业微信扫码，本地开发保留账号密码入口；
  同一入口按身份自动落到工作台或控制台。

## 技术栈

Vue 3 · TypeScript · Vite 6 · Vue Router 4 · Tailwind CSS 4 · Reka UI · Lucide · Axios。
基础组件在 `src/ui/` 内维护，主题通过语义令牌统一，支持浅色和深色模式。

## 快速开始

```sh
npm install
npm run dev
```

访问 `http://localhost:4810`。开发服务默认把 `/admin-api`、`/api` 代理到
`http://127.0.0.1:48081`，联调其他后端实例时覆盖即可：

```sh
VITE_PROXY_TARGET=http://127.0.0.1:48082 npm run dev
```

## 构建

```sh
npm run build      # 先 vue-tsc 类型检查，再产出 dist/
npm run test:portal-editor # HR 编辑器契约适配回归（不访问真实服务）
npm run test:portal-rollout # 菜单上线策略与状态回归（不访问真实服务）
npm run preview    # 本地预览构建产物
```

`dist/` 为静态产物，由后端或反向代理托管。

HR 文档工作台保留原门户的 20 类块、富文本、逐块预览、可调宽分栏、草稿历史与异步排版任务。
列表、编辑与预览均留在 OA 导航内，在当前标签页切换，返回时保留列表筛选。
工具栏和设置采用 OA 组件，正文按文档主题渲染；图片、表格、链接与完整富文本能力也复用到内容编辑。
原组件位于 `src/pages/portal/editor/legacy`，API 契约集中在 `editor/bridge/api.ts`，
视觉适配集中在 `editor/styles/oa-workspace.css`，旧样式只作用于局部 Frame 和浮层，动画名独立隔离。
可用 `VITE_PORTAL_DISPLAY_BASE_URL` 指定员工门户基址；未设置时引用文档跳到 OA 管理预览。

文档列表将标题、分类和签收信息集中展示，提供直接预览和编辑；手机使用卡片列表。历史版本在同一个窗口中选择版本和查看快照，不再叠加正文弹窗。列表预览、历史版本和排版任务共用 `editor/components/PortalDocumentReader.vue`：目录直接展示并随正文滚动高亮，手机上置；点击目录只滚动当前正文。草稿预览保留文档封面、签收与 PDF 能力。

排版任务使用 `editor/components/PortalLayoutJobsDialog.vue` 提供任务与正文分栏、大幅阅读、常驻目录、专注预览及桌面/手机阅读宽度。手机在任务列表和正文间切换，正文按纸张实际宽度调整多列布局；编辑器中的预览沿用当前文档主题。任务详情有独立加载、错误重试和空结果状态，快速切换不会串用其他任务结果。预览只读，应用仅更新编辑器，仍由用户保存草稿；可撤销回到应用前内容。

## 项目结构

```text
src/configs/       菜单与页面声明：控制台各板块、字段与路由都在这里配置
src/pages/         ShellPage 外壳、登录页、通用台账页；me/ 个人中心各视图
src/components/    导航、全局搜索、工作日历与通用表单
src/lib/           接口封装、会话、字典、格式化与提示
src/styles/        theme.css 设计令牌与公共组件，workspace.css 页面与外壳布局
```
